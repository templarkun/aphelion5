=== FORMAT SPEC ===
Same as "Test scenarios batch 1.txt". Summary:
1. Records of "key: value" lines, separated by one blank line, starting with "id:".
2. KEY ORDER: id, title, source, map, given, when, then, rule, assumption, issue, note
3. map: a Campaign 1 map (M1 = C1_M1). Only the shape is used.
4. given: stacks top first, "(q,r): TOP > next > ... > bottom". Tokens as in batch 1.
   Sectors not listed: face-up B_03 with a tile beneath. Unless stated: Command phase,
   no Alerts, Company V1, Flagship 6/6/6, one empty Overhaul slot, token supplies full,
   Reserve empty, no Modules, 6 Command tokens, the mission's own Order only.
5. when / then / rule / assumption / issue / note: as in batch 1.
6. "Legal actions" lists the action menu of Core Rules 8.1; Concede is always offered
   as well (Core Rules 10.3: "You may concede at any time").

id: T3_ACT_01
title: The action menu lists every action you can start
source: Core Rules 8.1
map: M1
given: (0,0): M_01 > fd. (0,1): fd:B_01. (1,0): G_05 > fd. (1,1): B_02[BS1] > fd.
       Demolition Blast (Module 1, cost 3 Yellow) ready, Reserve Yellow 3.
when: list legal actions

      (Bays 1, 2, 3), Drain a Gyro (G_05), Drain a Bio-shield (B_02), Issue an Order
      (Mission 1: 4 Command tokens), Overhaul, Concede. Not Resolve Alerts: no Alert.

id: T3_REV_01
title: Reveal a Bot
source: Core Rules 8.5, 3.7
map: M1
given: (0,1): fd:B_02 > fd.
when: Reveal (0,1)
then: B_02 face up on (0,1), now a unit. B_02 has no arrows, so no facing is asked.

      ask for one (facing stays 0). Tiles with arrows: the player chooses 0-5.

id: T3_REV_05
title: Power Node energy is split among ready Modules
source: Core Rules 4.6
map: M1
given: (0,1): fd:F_01 > fd. Demolition Blast (Yellow) and Charged Beam (Red, Module 26) ready.
when: Reveal (0,1)

      its colour: no question). No ready Blue Module: the Blue stays in the Supply. Overload
      starts.

note: CHANGED 2026-11-04 (designer, Q9) - energy you choose to place goes only on ready Modules of
      its colour; with none, it stays in the Supply (Core Rules 4.6, 5.3).
      Was: Yellow and Blue on Demolition Blast, Red on Charged Beam.
