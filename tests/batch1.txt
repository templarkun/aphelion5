################################################################################
# APHELION 5 - TEST SCENARIOS, BATCH 1 (structured, machine-oriented)
# Purpose: acceptance tests for a computer implementation. Each test is a small
# board state, one action, and the exact expected result.
# Rules semantics live in "Core Rules.txt" (geometry: Core Rules 3.8).
# Sources: the worked examples in Core Rules, made exact, plus edge cases.
################################################################################

=== FORMAT SPEC ===
1. Each test is a RECORD: "key: value" lines, records separated by one blank line,
   starting with "id:". Keys never repeat.
2. KEY ORDER: id, title, source, map, given, when, then, rule, assumption, issue, note
3. map: a mission map from Campaign1.txt (M1 = C1_M1, M2X = C1_M2X, ...). Only the
   map shape is used; ignore that mission's deployment unless "given" says otherwise.
4. given: the state. Notation for a sector's stack, top first:
     (q,r): TOP > next > ... > bottom
     "B_02[S1]"   = face-up B_02 with 1 Shield token
     "[D1]" Damage, "[BS1]" Bio-shield, "[BAR]" Barrier, "[AL]" Alert, "[WR]" Wreck
     marker, "[TICK]" "[MORTAR]" "[FB]" Fuse tokens, "f=N" facing (Core Rules 3.8)
     "fd" = face-down tile (contents given if they matter, e.g. "fd:B_01")
     "cleared" = no tiles
   Sectors not listed: top tile is face up B_03 with at least one tile beneath
   (so they never take Exposure and never affect Dark-sector checks).
   Unless stated: phase = Command; no Alerts; Flagship V1 with full Integrity
   (6/6/6); Shield supply 10; all Modules exhausted except those named.
5. when: the action(s), in order. "choose: ..." lists the player's choices.
6. then: the checks. Anything not mentioned must be unchanged.
7. assumption: a reading the test relies on that the rules do not state outright.
8. rule: the rule the test checks, quoted where it is new.
9. issue: a problem found in the rules while writing the test (OPEN until fixed).
10. note: what was changed to resolve an issue, with the date.
